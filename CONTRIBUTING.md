# Contributing

Open-source contributions to `core-engine` and `web-console` require a signed
Contributor License Agreement. Read and sign the agreement in `legal/CLA.md`
before submitting a pull request for review.

Requirements:

- Add focused tests for behavior changes
- Run `make test`
- Keep Pydantic, FastAPI, TypeScript, and configuration types strict
- Never commit secrets or proprietary enterprise assets
- Follow AGPLv3 obligations for distributed derivatives
